\# 5-тапсырма: Екі өлшемді массивтер (2-нұсқа)



\## Тапсырманың мақсаты



5×5 өлшемді матрица құру, оны кездейсоқ сандармен толтыру және әр жолда теріс элементтің бар-жоғын анықтау.



\## Бағдарламаның жұмысы



Матрица Random(1) арқылы -10 мен 10 аралығындағы сандармен толтырылады. PrintMatrix әдісі матрицаны экранға шығарады. FindNegativeRows әдісі әр жолды тексеріп, теріс элемент кездессе B массивіне 1, ал кездеспесе 0 мәнін жазады.



\## Сұрақтарға жауап



\*\*1. matrix\[i, j] жазбасында i мен j нені білдіреді? GetLength әдістері не қайтарады?\*\*



i – матрицаның жол нөмірі, j – баған нөмірі. GetLength(0) жол санын, ал GetLength(1) баған санын қайтарады.



\*\*2. Жолда теріс элемент табылғаннан кейін ішкі циклді жалғастыру керек пе? break не береді?\*\*



Теріс элемент табылғаннан кейін ішкі циклді жалғастыру міндетті емес. break командасы циклді тоқтатады, себебі сол жолда теріс элемент бар екені анықталды.



\*\*3. Ішкі цикл неше рет орындалады?\*\*



Матрицада 5 жол және 5 баған бар. Әр жолдағы ішкі цикл 5 рет орындалады, жалпы 25 ретке дейін орындалады.



\## Тесттер



Жеке тест: Random(1) арқылы алынған матрица. Бағдарлама нәтижесі экрандағы B массивімен тексеріледі.
