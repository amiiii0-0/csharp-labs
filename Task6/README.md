# 6-тапсырма: Символдар тіркесі (4-нұсқа)

## 1. Тапсырманың мақсаты

Пернетақтадан енгізілген мәтіндегі бас әріптердің санын анықтау және барлық бас әріптерді кіші әріптерге ауыстыру.

## 2. Бағдарламаның орындалуы

Бағдарлама пайдаланушыдан мәтін енгізуді сұрайды. Егер мәтін бос болса, енгізу қайта сұралады. ConvertText әдісі мәтінді символ бойынша тексереді. Егер символ бас әріп болса, оның саны біреуге артады және ол кіші әріпке ауыстырылады. Соңында өзгертілген мәтін мен бас әріптердің саны экранға шығарылады.

## 4. Бақылау сұрақтарына жауап

**1. text[i] нені қайтарады?**

text[i] мәтіннің i индексіндегі бір символын қайтарады. Оның типі char болады.

**2. Неліктен text[i] = 'a' деп жазуға болмайды?**

C# тілінде string өзгермейтін тип болып саналады. Сондықтан оның жеке символын тікелей өзгертуге болмайды. Жаңа нәтиже құрастыру қажет.

**3. Қазақ әріптері Ә, Ң, Ү дұрыс өңделе ме?**

char.IsUpper және char.ToLower әдістері Unicode әріптерімен жұмыс істейді. Сондықтан бұл қазақ әріптерін де өңдей алады. Оны жеке тест арқылы тексеруге болады.

**4. result += ch не істейді?**

Бұл команда символды result жолына қосады. Әр қосу кезінде жаңа мәтіндік жол құрастырылады, бастапқы мәтін өзгермейді.
