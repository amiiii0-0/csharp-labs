\# 5-тапсырма: Екі өлшемді массивтер (2-нұсқа)



\## Тапсырманың мақсаты



5×5 өлшемді матрица құру, оны кездейсоқ сандармен толтыру және әр жолда теріс санның бар-жоғын анықтау.



\## Бағдарламаның жұмысы



Матрица Random(1) арқылы толтырылады. Әр жол тексеріледі. Егер жолда кемінде бір теріс сан болса, B массивінің сәйкес элементіне 1 жазылады, әйтпесе 0 жазылады.



\## Тест нәтижелері



| Тест | Кіріс | Қолмен есептелген жауап | Бағдарлама жауабы |

|---|---|---|---|

| Жеке тест | Random(1) | Нақты матрица бойынша есептеледі | Нақты нәтиже енгізіледі |

| Өз тестім 1 | Барлық элементтері оң матрица | B = \[0, 0, 0, 0, 0] | B = \[0, 0, 0, 0, 0] |

| Өз тестім 2 | Барлық элементтері теріс матрица | B = \[1, 1, 1, 1, 1] | B = \[1, 1, 1, 1, 1] |



\## Сұрақтарға жауап



1\. matrix\[i, j] жазбасында i жолдың нөмірін, j бағанның нөмірін білдіреді. GetLength(0) жол санын, GetLength(1) баған санын қайтарады.



2\. Жолда теріс элемент табылғаннан кейін break қолдануға болады. Ол ішкі циклді тоқтатады, себебі сол жолда теріс сан бар екені анықталды.



3\. Ішкі цикл әр жол үшін 5 рет орындалады. Барлығы 5 × 5 = 25 рет орындалады.
