\## 4. break операторының қызметі



Бағдарламада break операторы ішкі циклде қолданылады.



Егер матрицаның ағымдағы жолынан бір теріс сан табылса, hasNegative айнымалысына true мәні беріледі. Одан кейін break операторы циклді тоқтатады.



Бұл оператор қалған элементтерді тексермей, келесі жолға өтуге мүмкіндік береді. Осылайша бағдарлама артық тексерулерді орындамайды.
